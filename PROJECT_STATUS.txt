🚀 DÉMARRER EN 5 MINUTES
════════════════════════════════════════════════════════════════════════════

  1️⃣  Cloner le repo
      $ git clone https://github.com/Knackie/progression-carnet
      $ cd progression-carnet

  2️⃣  Créer un projet Supabase (gratuit!)
      → https://supabase.com
      → Créer projet → Copier clés → .env.local

  3️⃣  Installer et lancer
      $ npm install
      $ npm run dev
      → http://localhost:3000

  4️⃣  Profiter! 🎉
      → S'inscrire
      → Créer une première entrée
      → Voir les graphiques

💾 BASE DE DONNÉES
════════════════════════════════════════════════════════════════════════════

  Table: progression_entries

  ┌─────────────────────────────────┐
  │ id: UUID (Primary Key)          │
  │ user_id: UUID (Référence User)  │
  │ sport: 'badminton' | 'chess'    │
  │ date: DATE                      │
  │ entry_type: 'match' | 'training'│
  │                                 │
  │ notes: TEXT                     │
  │ strengths: TEXT[] (3)           │
  │ weaknesses: TEXT[] (3)          │
  │ errors: TEXT[]                  │
  │ improvement_axes: TEXT[] (3)    │
  │ score: 0-10                     │
  │                                 │
  │ created_at: TIMESTAMP           │
  │ updated_at: TIMESTAMP           │
  └─────────────────────────────────┘

  🔒 Row Level Security activé
     → Chacun ne voit que ses données
