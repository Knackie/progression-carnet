# 🔥 INSTRUCTION ULTRA RAPIDE

## ⏱️ 2 MINUTES - C'est tout ce que tu dois faire

### ÉTAPE 1: Ouvrir Supabase
1. Va sur [supabase.com](https://supabase.com)
2. Connecte-toi à ton projet
3. Clique sur **SQL Editor** (menu gauche)
4. Clique sur **New Query**

### ÉTAPE 2: Copier-Coller le SQL
1. Ouvre le fichier: `COPIE_COLLE.sql`
2. **Copie TOUT** le contenu (Ctrl+A, Ctrl+C)
3. Dans Supabase, **colle** dans l'éditeur SQL (Ctrl+V)
4. Clique sur **Run** (ou Ctrl+Enter)

### ÉTAPE 3: Vérifier
Regarde en bas à droite:
- ✅ Si tu vois **"Success"** → C'est bon!
- ❌ Si tu vois des erreurs rouges → Relis le message

### ÉTAPE 4: C'est fini!
L'app fonctionne maintenant. Prêt? 🚀
